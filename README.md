# Atelier Étagères

Concevez vos étagères en bois massif dans le navigateur : dessinez, ajustez les dimensions à la souris ou au clavier, puis exportez la liste des planches à découper et un plan PDF à emporter en magasin.

Projet personnel en cours de développement. Voir [`docs/SPEC.md`](docs/SPEC.md) et [`docs/ROADMAP.md`](docs/ROADMAP.md).
